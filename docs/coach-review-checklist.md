## Review a saved scenario

1. Confirm that player alignment and eligibility are appropriate for the chosen practice context. The current sandbox is schematic and does not enforce a competition ruleset.
2. Check every defender's man target or zone responsibility. Does the call require a handoff, switch, bracket, carry, or rotation the current model does not represent?
3. Check cushion, leverage, and route distribution separately from speed. Record which movements are plausible and which are misleading.
4. Check each route's depth, breaks, and release timing. Straight-point paths do not implement realistic turning mechanics.
5. Compare lower/baseline/higher assumptions. Explain what the range shows and what it cannot establish.
6. Inspect the release snapshot. Would another defender or ball-flight/throw-placement issue matter? Never infer a completion probability from the nearest gap.
7. Compare with an example not used to set the ratings. Record contradictions, not just favorable outcomes.
8. Export the workspace with notes so the exact assumptions can be revisited.
